# 채용공고 매칭 앱

사람인 오픈API에서 공고를 받아 와서, **내 경력(CV)과 맞는 정도**를 점수로 매기고 **집에서 가까운 지역**만 골라 보여 주는 Streamlit 앱입니다.

## 실행 방법

1. Anaconda Prompt를 열고 이 폴더로 이동
   ```
   cd "D:\헬스케어6기\채용공고 크롤링"
   ```
2. 처음 한 번만 필요한 라이브러리 설치
   ```
   pip install -r requirements.txt
   ```
3. 앱 켜기
   ```
   streamlit run app.py
   ```
   브라우저에 `http://localhost:8501` 이 열립니다.

API 키가 없으면 **가짜 공고(회사 이름 앞에 '(예시)')** 로 화면이 나옵니다.

## API 키를 받으면

1. `.env.example` 파일을 복사해서 이름을 `.env` 로 바꾸기
2. `SARAMIN_ACCESS_KEY=` 뒤에 키 붙여 넣기 (따옴표 없이)
3. (선택) 실제 집 위치를 `HOME_NAME`, `HOME_LAT`, `HOME_LON` 에 넣기 — 비워 두면 `profile.yaml` 의 대략 기준점(용인시청)으로 거리를 잽니다
4. 앱을 끄고(Ctrl+C) 다시 켜기 → 사이드바의 **[새 공고 불러오기]** 클릭

`.env` 는 `.gitignore` 에 들어 있어서 GitHub에 올라가지 않습니다. 키와 집 위치처럼 공개하면 안 되는 값은 여기에만 두세요.

### 키 받은 뒤 확인할 것

사람인 API 문서를 보고 짐작해 쓴 부분이라, 첫 실행 때 한 번 맞춰 봐야 합니다.

- 요청 변수 이름: `loc_mcd`(1차 지역), `count`, `sort` → `saramin.py` 의 `fetch()`
- 응답에서 지역 이름이 `경기 > 용인시 기흥구` 모양으로 오는지 → 다르면 `profile.yaml` 의 `match` 글자 수정
- 오류가 나면 사이드바에 사람인 오류 코드가 뜹니다

## 채점 방식 (무료)

공고의 **제목, 키워드, 직무 분류, 업종**에 `profile.yaml` 기준표의 단어가 몇 개 들어 있는지로 점수를 매깁니다.

| 단계 | 규칙 |
|---|---|
| 묶음 점수 | 묶음마다 무게가 있음. 묶음 안의 단어가 2개 이상 맞으면 무게 전부, 1개면 절반 |
| 합계 | (받은 점수 ÷ 무게 합계) × 100 |
| 부족한 점 | `gaps` 단어가 나오면 하나당 -5 |
| 다른 방향 | `exclude` 단어(영업 등)가 나오면 -40 |
| 경력 조건 | 신입만 뽑으면 경력 직결 탭 -30, 신약 AI 탭 -5 / 경력 상한이 8년 미만이면 -15 |

- 영문 대소문자, 띄어쓰기, 하이픈은 무시하고 비교합니다 (`LC-MS/MS` = `lcms/ms`)
- `PK`, `AI`, `R` 처럼 3글자 이하 영문은 다른 단어 속에 숨은 경우(`SPK`)를 빼고 셉니다
- 사람인 API는 공고 **본문 전체를 주지 않아서**, 자격요건 문장까지는 비교하지 못합니다

## 지역·거리

- `profile.yaml` 의 `regions` 에 있는 지역만 보여 줍니다 (재택·원격 공고는 예외)
- 거리는 집과 지역 중심 사이의 **직선거리**입니다. 실제 통근 시간과는 다를 수 있어요
- 화성시는 공고에 동탄 여부가 안 나와서 동탄 기준으로 계산합니다

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `app.py` | 화면 |
| `saramin.py` | 사람인 API 호출, 응답 정리 |
| `scoring.py` | 채점, 지역·거리 판정 |
| `storage.py` | 공고·표시(관심/지원함/숨김)·호출 수 저장 |
| `profile.yaml` | 기준표, 지역, 검색어 — **기준을 바꿀 땐 이 파일만 수정** |
| `sample_jobs.json` | 키가 없을 때 쓰는 가짜 공고 |
| `data/jobs.db` | 받아 온 공고와 표시 기록 (자동 생성, GitHub 제외) |
